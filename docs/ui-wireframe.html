CEN UI/UX Blueprint

Wireframe struktur untuk layar Wallet (baru) dan layout desktop aplikasi mining. Angka dan teks di sini adalah penanda posisi, bukan data sungguhan. Palet memakai token aplikasi yang sudah berjalan.

1. Arsitektur Navigasi

Sekarang 4 destinasi. Usulan tambah Wallet di posisi ketiga, jadi 5. Di phone, 5 item masih dalam batas nyaman bottom nav.

⚡Mining
●Workers
▢Wallet
⚙Node
☰Activity
Urutan usulan
Mining → Workers → Wallet → Node → Activity

Alasan Wallet di posisi 3: setelah orang selesai mining, langkah berikutnya melihat dan memindahkan hasilnya. Node dan Activity layar teknis yang jarang dibuka.

Item putus-putus = destinasi baru yang diusulkan.

9. Checklist Serahkan ke Desainer

#Butir
1Palet memakai token yang ada, tidak ada warna baru tanpa alasan
2Aksen tidak dipakai di semua elemen
3Tidak ada emoji sebagai hiasan di teks UI
4Angka di state kosong atau loading ditandai jelas, tidak ada angka karangan
5Setiap layar punya empty, loading, dan error state
6Target sentuh minimal 44 x 44 px dengan jarak antar tombol
7Semua interaksi punya padanan tap, tidak ada yang hover-only
8Bottom nav tidak menutupi konten terakhir
9Ada tiga keadaan lebar, bukan dua
10Tidak ada scroll horizontal di lebar paling sempit
11Setelah wallet ada, 12 kata tidak bisa dilihat tanpa penjaga
12Ada penanda jelas kalau pengguna di testnet
